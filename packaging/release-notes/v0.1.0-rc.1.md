The first release candidate of icygui, a native desktop client for the Icinga 2 REST API (macOS and Linux). It is meant for a trial against a real Icinga by on-call engineers, before v1.

**Install** (macOS and Linux):

```sh
curl -fsSL https://raw.githubusercontent.com/alexykn/icygui/main/install.sh | bash -s -- --version 0.1.0-rc.1
```

Before connecting it to a production Icinga, go through the [first-run checklist](https://github.com/alexykn/icygui/blob/main/docs/first-run.md): a least-privilege `ApiUser`, the certificate, what normal looks like (including quiet mode while the window is closed) and what to report.

**Known limitations**

- The macOS desktop integration has only been compiled and unit-tested so far: the menu-bar icon, notifications with *Acknowledge* and *Open*, launch at login, keychain prompts and quiet mode's window visibility have never run on a real Mac. The [Mac checklist](https://github.com/alexykn/icygui/blob/main/docs/spikes.md#still-to-run-on-a-mac) lists what to look at.
- The macOS app is ad-hoc signed and not notarized; `install.sh` re-signs it with a local identity. A browser download needs *Open Anyway* once.
- Not in this release (planned for v1): multi-view dashboards, the host-group grid, the full cluster health view, the light theme.

**Reporting problems:** open an issue with what you did, what you expected, what happened and when, `icygui --version`, your OS and Icinga's version. The log (`~/.local/state/icygui/logs/icygui.log` on Linux, `~/Library/Logs/io.github.alexykn.icygui/icygui.log` on macOS) contains host and service names but never passwords; share it as you would those names.
