10Selecting several objects in the palette

The palette learns to select several rows. shift-↑↓ extends the selection from the cursor, ctrl-a (⌘A) selects every match, ctrl-click (⌘-click) toggles a row and shift-click selects a range. The selection is drawn as one rounded outline per block of selected rows, filled with the marked-row tint of the lists; the cursor keeps its selected-row background inside it. There are no check marks, and a row never moves when it is selected. Only object rows can be selected: hosts, services, and actions on them. Commands, dashboards and environments are skipped. The footer counts the selection and says what Enter does. With a verb (ack db), Enter opens ONE dialog for every selected object, listing each one. Without a verb (db-prod), Enter opens the selected hosts together, like Icinga Web's multi-host view: a summary row per host with its services under it, and a bulk action bar. The view arrives with nothing marked, and its bar offers mark all problems. A selection of services only opens the same way, grouped by their hosts. That view can be pinned as a tab or saved as a dashboard. A verb query now lists every match (it used to stop at six), so the all N matches row, now first, counts objects you can see. Editing the query clears the selection. Esc clears the selection first and closes the palette on the second press.
