08Sharing dashboards through the clipboard, as YAML

Copy a dashboard or a whole group as YAML text, then paste it into a chat, a wiki page or a ticket; a colleague pastes it into their icygui. copy as YAML is in the dashboard's and the group's ··· menus and in the palette. A toast confirms what was copied. Pasting (ctrl-v on the sidebar, paste dashboards in the footer's + menu, or the palette) never imports straight away: a preview dialog shows what the YAML holds, what clashes with the groups and dashboards already there, and what to do about each clash, with the YAML itself beside it. The exported file uses the same format (format: icygui-dashboards); rc1's TOML files still import.
