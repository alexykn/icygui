09Autocomplete in the filter field, in the style of Zed

The dashboard editor's filter field (and every other filter field) completes as you type. The completions come from the parser at the cursor and from the live data: attributes with their type and a description after host. and service.; after vars., the custom variables that exist, ranked by how many objects have them; inside a string, the values in use; functions with their signatures. Matching is fuzzy, with the matched characters in the accent colour. Tab or Enter accepts, ctrl-space opens the list, Esc closes it. The popup is the app's menu card; a documentation card beside it explains the selected item, and flips to the left when there is no room on the right. Hovering a name shows the same help. A parse error is underlined where it happens. Each frame has a zoomed crop.
