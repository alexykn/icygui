07Lists of every downtime, comment and acknowledgementrevised

Three lists across all objects: downtimes, comments and acknowledged problems, from data icygui already loads. They open from the palette as tabs in the sidebar's open section only (there are no sidebar dashboards for them). Each list header has an only mine switch for what the environment's author set. The rows are today's list rows: the object's state circle in the mark slot (hollow = handled, so an object whose downtime is in effect is a hollow ring in its state colour, an OK host too), service on host, a second line with the details, and the tag. The downtime list separates in effect and upcoming with section headers, styled like the grouped list's group headers. Selection, the selection bar and the keys work as in every list. Bulk removal always confirms and lists every target. Config downtimes are locked and can't be removed.
