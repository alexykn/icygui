PLAN.md §4.2, Knowing when icygui is blind. (A) No live data, always on, no setup: an environment that notifies and has had no live data for more than 2 minutes (connection lost, credentials refused, stalled, stale, heartbeat dead) gets one desktop notification naming it, the reason and since when, and one when it recovers; the tray gets a blind look and each environment’s age; every page of that environment shows a banner until data is live again. (B) The heartbeat, optional per environment: an always-OK check icygui watches on the event stream; the cluster health page shows it next to the health line. In this page’s story the prod-cluster stream stalled at 02:14; it is now 02:17.
